# How to Scaffold a Laravel + React Project

Setting up a Laravel + React stack from scratch means writing the same boilerplate every time: Eloquent models, migrations, API controllers, route files, CORS config, and a separate Vite frontend with typed API calls. StackInit eliminates all of that in under two minutes.

This guide walks through generating a production-ready **Laravel API + React (Vite) frontend** with StackInit, using a real-world SaaS example: a multi-tenant task management app with Users, Teams, Projects, and Tasks.

---

## Prerequisites

- PHP 8.2+ and Composer
- Node.js 18+ and pnpm (or npm)
- Basic familiarity with Laravel and React

---

## Step 1 — Pick your stack in StackInit

Open [StackInit](/create) and select **Laravel** as your backend framework. On the frontend panel, choose **React + Vite**. This combo generates:

- A Laravel 11 API project (controllers, models, migrations, routes, CORS middleware)
- A React 18 + TypeScript frontend with Vite, pre-configured to proxy to the Laravel API

---

## Step 2 — Model your data visually

In the **Models** step, define your entities. For this example:

- **User** — `name: string`, `email: string (unique)`, `role: enum(admin, member)`
- **Team** — `name: string`, `slug: string (unique)`
- **Project** — `title: string`, `description: text (nullable)`, `status: enum(active, archived)`
- **Task** — `title: string`, `done: boolean`, `due_date: date (nullable)`

StackInit lets you add fields with types, nullable flags, unique constraints, and default values — all without touching a migration file.

---

## Step 3 — Define relations

Switch to the **Relations** step and wire up:

- `User` **belongsToMany** `Team` (pivot: `team_user`)
- `Team` **hasMany** `Project`
- `Project` **hasMany** `Task`
- `Task` **belongsTo** `User` (assignee)

StackInit renders a live ERD as you define relations so you can catch mistakes before generating.

## Step 5 — Generate and download

Click **Generate**. StackInit produces a `.zip` containing:

```
laravel-api/
├── app/
│   ├── Http/Controllers/Api/
│   │   ├── UserController.php
│   │   ├── ProjectController.php
│   │   └── TaskController.php
│   ├── Models/
│   │   ├── User.php        # With Team relationship
│   │   ├── Team.php
│   │   ├── Project.php
│   │   └── Task.php
│   └── Http/Resources/
├── database/migrations/    # All tables with foreign keys
└── routes/api.php          # RESTful routes registered

react-frontend/
├── src/
│   ├── api/                # Axios client + typed endpoints
│   ├── pages/              # Route-based pages
│   └── components/
├── vite.config.ts          # Proxy to Laravel API
└── package.json
```

---

## Running the project

```bash
# Laravel API
cd laravel-api
composer install
cp .env.example .env && php artisan key:generate
php artisan migrate
php artisan serve

# React frontend (new terminal)
cd react-frontend
pnpm install
pnpm dev
```

The frontend runs on `http://localhost:5173` and proxies API calls to `http://localhost:8000`.
