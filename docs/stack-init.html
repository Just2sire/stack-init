Features

Everything you always write by hand

Smart Migrations
Every Blueprint type supported with all modifiers — nullable, unique, index, default — with proper cascades for FK.
Auto Validation Rules
StoreRequest and UpdateRequest generated with context-aware rules. Enum types get `in:`, FK get `exists:`, and more.
Pest Tests
5 scenarios per model: index, show, store (valid + invalid), update, destroy. Soft delete handled automatically.
Intelligent Fakers
Factory values inferred from field name first, type second. `email` gives `safeEmail()`, `body` gives `paragraphs()`.
Eloquent Relations
hasMany, belongsTo, belongsToMany, morphs — generated in the model with proper methods and FK validation.
React ZIP Export
React/Next.js projects generated directly in your browser — no server, no install. Download and unzip.
